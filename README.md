# Eulerian Path Puzzle（一筆書きパズル）

離散数学のグラフ理論における**オイラー路（一筆書き）**をテーマにしたパズルゲームです。  
Python（Pygame / NetworkX）を使用し、必ず解が存在するグラフの自動生成や、残余グラフに基づくリアルタイムヒント機能を実装しています。

## 主な機能

* **ステージ自動生成**：レベルに応じて頂点数・辺の密度が変化し、オイラー路が存在するグラフを自動生成します。
* **リアルタイムヒント（`[H]`キー）**：現在の状態から残りの未訪問辺（残余グラフ）を解析し、一筆書きを継続できる次の1手を提示します。
* **手詰まり判定と正解表示**：移動可能な辺がなくなった時点で手詰まり（STUCK）となり、正解ルートの1つを矢印と番号でオーバーレイ表示します。
* **スコアシステム**：辺を引くごとに加点され、クリア時にはレベルに応じたボーナスが入ります。

## 操作方法

| 操作 / キー | 機能 |
| :--- | :--- |
| **左クリック** | 始点の選択 / 隣接するノードへ線を引く |
| **`[H]`** | ヒントを表示（次に選ぶべきノード・辺をハイライト） |
| **`[Z]`** | 1手戻す（Undo）※手詰まり時は使用不可 |
| **`[R]`** | 現在のステージを最初からやり直す（Retry） |
| **`[N]`** | 同じレベルで新しいステージを生成する（New） |
| **`[SPACE]`** | ステージクリア後に次のレベルへ進む |

## スコア仕様

* **線を1本引く**：`+100 pt`
* **ステージクリア**：`+300 pt × 現在のレベル`
* **Undo（`[Z]`）使用**：`-50 pt`
* **ヒント（`[H]`）使用**：`-150 pt`
* **リトライ（`[R]`）使用**：ステージ開始時のスコアにリセット

## セットアップ・実行方法

Python 3.8以上を推奨します。必要なライブラリをインストールして `main.py` を実行してください。

```bash
pip install pygame networkx
python main.py
```
